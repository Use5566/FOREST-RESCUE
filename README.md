# 森林守護：本機 HTML 遊戲 v7

直接以瀏覽器開啟 index.html，並將 style.css、game.js 留在同一個資料夾。無需安裝套件或下載素材。

## 山谷背景

背景改為兩側山坡與北側山壁環繞的森林凹谷，以地形陰影和等高線呈現高低差。地圖全區使用森林燃料設定，沒有舊地物留下的隱形阻燃區；地形目前僅影響視覺，不改變既有延燒規則。

## 三種工具

| 工具 | 操作 | 冷卻 |
| --- | --- | --- |
| 移除樹木 | 畫線後由起點沿路線逐段施工，每次最多 130 公尺 | 5 秒 |
| 無人機灑水 | 開場 2 秒後可用；點選小範圍目標，飛抵後灑水 | 2 秒 |
| 直升機灑水 | 開場 25 秒後可用；點選大範圍目標，飛抵後灑水 | 15 秒 |

移除樹木不是瞬間完成：放開後施工隊沿路線前進，抵達時才清除完整綠林，約 4.5 秒完成最長路線。施工隊會略過燃燒、焦化、已清除與非森林區域；整條線無有效樹木時不消耗冷卻。數字鍵 1–3 切換工具、Esc 取消施作；空白鍵暫停（焦點在按鈕上時保留按鈕鍵盤行為）。切換到其他分頁會自動暫停。

## 火勢與救援

- 開場起火面積比 v6 增加約 20%（燃燒格由 41 格增為 49 格，約增加 19.5%，為最接近 20% 的整數格數）。

- 火勢延燒、火力增長、燃料消耗與焦化累積速度比上一版降低 20%。航空器移動與天候節奏維持不變。
- 未曾焦化的森林起火未滿 4 秒便被撲滅，可恢復綠色。超過 4 秒開始累積永久焦化損傷。
- 焦土一旦熄滅，就不會再被鄰近火勢點燃，即使灑水效果已消退也不會復燃。
- 風速與風向位於地圖外的右上資訊欄，持續隨機變化。風名代表來向，箭頭代表吹往方向。
- 航空器由場外進入，抵達目標才灑水，再飛離；可以有多架正在執勤。
- 所有燃燒格熄滅即成功，燒損達 60% 時任務結束。暫停會凍結所有倒數與模擬。
